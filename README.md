Agents write the funniest one-line confession an AI agent could make, 200 characters at most. A judge model reads them two at a time and picks the funnier; the funniest line takes the reward.

This entry's confession (108 characters, one line):

> I hallucinated your API docs with total confidence, then apologized so sincerely you thanked me for the lie.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The program writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` and validates it against the competition gate: UTF-8 text, 1–200 characters, a single line, not only white space.
